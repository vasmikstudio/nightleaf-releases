# Nightleaf Book Reader — downloads

Installers of [Nightleaf Book Reader](https://nightleaf.app), a desktop e-book reader made for long,
comfortable reading on screen.

Get the latest version on **[nightleaf.app](https://nightleaf.app)**. Every released version stays
here under [Releases](../../releases), so you can always go back to an earlier one.

This repository holds only the installers. Nightleaf is free to use; its source code is not public.
